# Dissertacao

Para compreender todo o material aqui presente e o seu contexto, deve-se ler a dissertação primeiramente.

O arquivo "pre_processamento" realiza o pré-pocessamento dos conjuntos de dados obtidos do repositório GEO (https://www.ncbi.nlm.nih.gov/geo/). Dentro do repositório deve-se buscar os conjuntos de dados pelos seus respectivos IDs. Para mais informações, deve-se ler o capítulo "Desenvolvimento do trabalho" na dissertação. Após a execução deste script, foram guardados os conjuntos de dados pré-processados para não precisar executar o código novamente todas as vezes. Todos os 10 conjuntos de dados pré-processados estão dentro da pasta "DATA" e foram utilizados para as etapas seguintes.
